## 📋 Resumen

ISO/AWI TS 25481 especifica un modelo de gobernanza para **Organizaciones Autónomas Descentralizadas (DAOs)**, cubriendo aspectos on-chain y off-chain.

### 2. Roles y Responsabilidades

| Rol | Responsabilidad | Poder |
|-----|-----------------|-------|
| **Fundador** | Visión estratégica | Veto temporal |
| **Asamblea** | Votar SIPs | Soberanía total |
| **Consejo de Ética** | Auditar cumplimiento | Veto ético |
| **Comité Técnico** | Desarrollo del estándar | Propuesta técnica |
| **Tesorería** | Gestión de fondos | Ejecución presupuestaria |

### 3. Proceso de Votación (On-Chain)

| Etapa | Duración | Descripción |
|-------|----------|-------------|
| **Propuesta** | - | Requiere 1,000 $SYMBIO |
| **Discusión** | 3 días | GitHub Discussions |
| **Votación** | 7 días | Smart Contract |
| **Quórum** | - | 10% del suministro |
| **Ejecución** | 2 días | Automática si aprueba |

## 📋 Tipos de Propuestas (SIPs)

| Tipo | Descripción | Quórum |
|------|-------------|--------|
| **SIP-Protocolo** | Cambios en Smart Contracts | 20% |
| **SIP-Legal** | Cambios en licencia | 15% |
| **SIP-Tesorería** | Uso de fondos | 10% |
| **SIP-Comunidad** | Nuevos miembros | 5% |
